# Voxd

Voxd is a local speech AI runtime.

It provides a unified interface for running speech models from different inference engines through a single CLI and HTTP API.

The goal is to make downloading, managing, and serving speech models as simple as running a single command.

## Current Status

This repository currently includes:

* Runtime foundation
* FastAPI server
* Command-line interface
* Configuration system
* Structured logging
* Health endpoint
* Version endpoint

Additional features such as model management, downloads, engine integrations, and speech generation are under active development.
